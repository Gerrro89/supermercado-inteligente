# Memoria de desarrollo

- Se eligió una estética de papelería editorial: azul cobalto, rojo tomate, lima, crema y tinta azul oscuro.
- La referencia de arte generada mezcla supermercado isométrico, gouache y trazos de cuaderno; funciona mejor como panel de marca que como fondo completo.
- El reto se diseñó para 1 jugador o parejas trabajando frente a la misma pantalla. El texto siempre nombra la dinámica de parejas.
- La equivalencia didáctica central es `25% = 1/4 = 0,25`; la tarjeta también muestra `ahorras $2.000` sobre queso de $8.000.
- El botón de calculadora está presentado como verificación después del razonamiento, no como requisito para avanzar.
